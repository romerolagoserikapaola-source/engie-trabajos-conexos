# APP ENGIE - Gestión de Trabajos Conexos V1.2

## Mejora principal
Se incorporó el mapa de sectorización ENGIE proporcionado por el usuario.

### Funciones del mapa
- Visualización del mapa real.
- Zoom + / −.
- Restablecer escala.
- Pantalla completa.
- Desplazamiento dentro del visor.
- Selección de sectores 1 al 8.
- Botones rápidos S1–S8 vinculados al desplegable.
- Campo de referencia / punto específico.

### Sectores configurados
1. Bocatoma Quitaracsa
2. Túnel de acceso a Bocatoma
3. Talud izquierdo
4. Galería de Captación
5. Talud / acceso intermedio
6. Talud derecho / acceso al Desarenador
7. Desarenador
8. Vía de acceso / plataforma

Esta versión continúa utilizando `localStorage` para pruebas de interfaz.
La siguiente fase puede conectarse con Google Sheets, Apps Script y Drive.
